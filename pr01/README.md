# PR-1. Настройка окружения и первый анализ данных

## Target
Настроить рабочее окружение Python, загрузить стандартизированный датасет «tips» и выполнить глубокий первичный осмотр структуры данных.

## Details & Implementation
- Загрузка библиотек Pandas, Seaborn, Matplotlib.
- Анализ размерности, типов столбцов и выявление пропусков.
- Расчет базовых статистических параметров (среднее, медиана, квартили).
