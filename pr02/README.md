# PR-2. Разведочный анализ данных (EDA)

## Target
Выполнить разведочный анализ данных (EDA), выявить закономерности и построить матрицу корреляций числовых признаков.

## Details & Implementation
- Фильтрация числовых признаков из датасета.
- Расчет коэффициентов корреляции.
- Построение тепловой карты (heatmap) с помощью Seaborn и сохранение визуализации.
