# PR-3. Сборка пайплайна предобработки

## Target
Спроектировать надежный и безопасный конвейер предобработки данных (ColumnTransformer + Pipeline) с целью предотвращения утечки данных (data leakage).

## Details & Implementation
- Разделение выборки на обучающую и тестовую (	rain_test_split).
- Раздельная обработка числовых (медиана + стандартизация) и категориальных (мода + OneHotEncoding) признаков.
