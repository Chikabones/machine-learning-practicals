# PR-6. Классификация текстов

## Target
Реализовать пайплайн анализа тональности текстовых данных с использованием векторизации TF-IDF и Наивного байесовского классификатора.

## Details & Implementation
- Создание текстового корпуса и удаление стоп-слов.
- Векторизация документов с помощью TfidfVectorizer.
- Обучение MultinomialNB и оценка точности.
