## Структура репозитория (Часть 3А, Вариант B)
Репозиторий структурирован по отдельным практическим работам в соответствии с методическими требованиями. Каждая папка содержит полноценный исполняемый скрипт решения и файл документации:

| Папка / Работа | Тема занятия | Основные инструменты / Модели |
| :--- | :--- | :--- |
| **pr01/** | Настройка окружения и EDA | Pandas, Seaborn, Matplotlib |
| **pr02/** | Разведочный анализ данных | Матрица корреляций, Heatmap |
| **pr03/** | Пайплайн предобработки | ColumnTransformer, Pipeline |
| **pr04/** | Регрессионный анализ | Linear Regression, MAE, R² |
| **pr05/** | Бинарная классификация | Logistic Regression, ROC-AUC |
| **pr06/** | Классификация текстов | TfidfVectorizer, MultinomialNB |
| **pr07/** | Ансамблевые модели | RandomForest, GridSearchCV |
