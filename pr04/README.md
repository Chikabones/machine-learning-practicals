# PR-4. Регрессионная модель

## Target
Построить модель прогнозирования непрерывной величины на базе линейной регрессии и оценить качество предсказаний.

## Details & Implementation
- Объединение препроцессора и модели LinearRegression в единый пайплайн.
- Оценка качества с помощью метрик MAE (Mean Absolute Error) и R² (Coefficient of Determination).
